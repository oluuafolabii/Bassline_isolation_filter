# Bass-frequency isolation with windowed FIR filters

A MATLAB experiment in **low-frequency component isolation**, not instrument/source separation. It designs and compares windowed-sinc low-pass FIR filters on four audio clips, then measures their frequency response and the energy retained or removed from each clip.

## Method and recorded results

The experiment crosses **3 cutoffs** (150/200/250 Hz), **6 even orders** (50/100/200/500/1000/2000) and **4 windows** (rectangular/Hann/Hamming/Blackman): **72 filter designs**. [`m_03_design_filters.m`](FIR_Bass_Isolation_Project/matlab_code/m_03_design_filters.m) constructs symmetric, DC-normalized windowed-sinc coefficients and a `fir1` comparison for each design. [`m_04_evaluate_filters.m`](FIR_Bass_Isolation_Project/matlab_code/m_04_evaluate_filters.m) evaluates frequency responses; [`m_05_apply_filters.m`](FIR_Bass_Isolation_Project/matlab_code/m_05_apply_filters.m) filters each clip for **288 clip/filter combinations**, with detailed exported WAVs and plots for eight finalists. The causal output is shifted by half the filter order for comparisons; a separate `filtfilt` example uses the 200 Hz, order-1000 Hamming design.

The repository's objective scoring selected **200 Hz, order 1000, Blackman (F6)**. In [`filter_metrics.csv`](FIR_Bass_Isolation_Project/tables/filter_metrics.csv), its stopband attenuation is **76.5 dB** (stopband defined from 2 × cutoff), measured −1 to −40 dB transition width **151.8 Hz**, and group delay **500 samples / 10.42 ms** at 48 kHz. Across four clips, [`final_design_choice.md`](FIR_Bass_Isolation_Project/notes/final_design_choice.md) reports average below-cutoff energy retention **0.8774** and above-cutoff energy ratio **0.039886**. These are PSD-derived, band-specific ratios, **not** percentages of instrument separation. For comparison, order-1000 Hamming at 200 Hz has a narrower recorded transition (**113.0 Hz**), higher average retention (**0.9209**) and lower above-cutoff ratio (**0.030433**), but less attenuation in the separately defined stopband (**59.1 dB**). The selection depends on the particular scoring weights; it is not a universal optimum.

## Reproduce or review

Use MATLAB with Signal Processing Toolbox; [`notes/dependency_check.txt`](FIR_Bass_Isolation_Project/notes/dependency_check.txt) records a successful check in **R2025a**. From `FIR_Bass_Isolation_Project/matlab_code/`, run `m_00_run_all.m` to regenerate stages 0–7, then run `m_08_review_and_validate.m` separately for the additional automated checks. **These scripts overwrite generated files and some notes**; use a disposable copy if preserving the checked-in artifacts matters. There is no MATLAB or Octave executable in the environment used for this README update, so the numerical pipeline was not rerun here. The checked-in dependency log and result tables are historical evidence, not a fresh validation run. The master runner does **not** call the stage-8 validation script, and no generated `notes/validation_report.txt` is present.

The listening notes and cutoff-observation notes are still [unfilled templates](FIR_Bass_Isolation_Project/notes/listening_test_notes.md); no completed listening study is demonstrated. The WAV exports are individually peak-normalized *after* energy metrics are computed, so the saved audio files are not on the same amplitude scale as the measured energy ratios. A low-pass filter preserves every source in its passband; it cannot extract an isolated bass instrument from a mix.
